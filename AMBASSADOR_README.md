## FAQ

**Q: What if recruitment falls short of 50-100 ambassadors?**
A: We have contingency strategies built in - referral incentives, coordinator recruitment, mentor program expansion. The target is 50 minimum, 100 optimal. We'll adjust incentives if needed and can extend recruitment into early October.

**Q: Can ambassadors start if portal isn't ready by Sept 6?**
A: Yes! We have a minimal viable version ready. They can use email/spreadsheets initially while Phase 2 portal features deploy. The MVP core features (dashboard, events, reporting) will be live by Sept 6.

**Q: What's the approval process for budget overruns?**
A: Minor variations (5-10%) are expected. For larger overruns, submit a proposal to Finance/CFO with justification. We have $5-10K contingency built in.

**Q: How do we handle ambassador dropouts?**
A: Expected 5-10% in first month. We have replacement recruitment running continuously. Buddy system and support help reduce churn. Exit interviews help us improve.

**Q: Can we recruit ambassadors in October/November?**
A: Yes! We planned recruitment ending Sept 30, but the program is ongoing. We can recruit additional ambassadors continuously to hit growth targets.

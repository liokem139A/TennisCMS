## Emergency Escalation Path

**If Daily Opens < 15% after 24 hours:**
1. Review subject line effectiveness
2. Consider sending to secondary list at different time
3. Check spam folder (request team members check)
4. Verify tracking code working properly

**If No Tier 1 Responses After 48 hours:**
1. Audit list quality
2. Review targeting (wrong list?)
3. Consider resend to non-openers
4. Adjust follow-up messaging

**If Response Rate < 2% After 72 hours:**
1. Emergency all-hands review
2. Consider multi-channel campaign acceleration
3. Get executive sponsor to make calls directly
4. Consider campaign redesign for next phase

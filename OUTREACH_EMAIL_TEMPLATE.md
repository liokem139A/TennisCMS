## Email Strategy Overview

**Key Principles**:
1. **Personalized**: Reference specific company/prospect details
2. **Value-First**: Lead with what's in it for them, not what we need
3. **Low-Pressure**: "Let's explore possibilities" tone, not hard sell
4. **Specific**: Mention concrete opportunity or mutual interest
5. **Clear CTA**: Simple ask - 30 min call, specific calendar link

**Best Practices**:
- Subject line should be specific and intriguing (not generic "Partnership Opportunity")
- Opening line should create immediate relevance
- Body should be 3-4 short paragraphs max
- Personalization (first name, company details) = 3x higher response rate
- Include calendar link for easy scheduling
- Follow-up: Send 3-5 days after if no response

## EMAIL CUSTOMIZATION CHECKLIST (Before Sending)

Before hitting send on any email:

- [ ] Prospect name + company name match the person/company researched
- [ ] Subject line is specific and intriguing (not generic)
- [ ] First paragraph creates immediate relevance/connection
- [ ] Body references specific detail about their company/mission
- [ ] CTA is clear and easy ("30 minutes next week")
- [ ] Calendar link is included (or phone number for local prospects)
- [ ] Signature includes all contact info (name, title, phone, email)
- [ ] Tone matches prospect type (corporate vs. casual vs. premium)
- [ ] Length is 3-4 paragraphs max
- [ ] Personalization is genuine (not every prospect = same email)

## SUBJECT LINE EFFECTIVENESS GUIDE

**High Response Rate Subject Lines** (use these):
- Specific and personalized: "Quick question about [Industry/Company]"
- Curiosity/partnership: "[YourName] at [Community] - partnership idea"
- Direct opportunity: "Partnership opportunity with [Community Name]"

**Medium Response Rate**:
- Generic: "Partnership Opportunity"
- Too formal: "Strategic Collaboration Proposal"

**Low Response Rate** (avoid):
- All caps: "PARTNERSHIP OPPORTUNITY!!!"
- Too sales-y: "Don't miss this amazing opportunity"
- Too vague: "Hi [Company]"
